# Replay API

[English](../en/README.md)

`TUFReplay.ReplayApi`는 오버레이, 키뷰어 같은 모드가 TUFReplay의 기록과 리플레이에 참여하는 방법입니다.

- **리플레이 따라가기.** 판을 리플레이하는 동안 모드는 리플레이의 시계와 기록된 키를 받습니다. 게임 안에서 재생할 때와 영상으로 렌더할 때 호출이 같아서, 리플레이 경로를 하나만 만들면 됩니다.
- **판마다 값 저장.** 시도 횟수, 설정, 심박수 같은 모드의 값을 기록된 판마다 저장하고, 리플레이 때 그 판의 그 시점 값으로 돌려받습니다.
- **영상에 나오기.** 렌더할 때 모드의 캔버스를 영상에 넣거나, 모드가 만든 영상을 그 위에 겹칩니다.

`ApiVersion`은 2입니다.

## 순서대로 읽기

1. [TUFReplay에 연결하기](1-connect.md): TUFReplay.dll을 참조하지 않고 API를 찾아 등록합니다.
2. [리플레이 따라가기](2-follow-a-replay.md): 실제 입력 대신 리플레이의 키와 시계를 보여 줍니다.
3. [판마다 값 저장하기](3-run-values.md): 값마다 id 하나, 판이 시작할 때의 값, 판 중에 바뀌는 값, 돌려받기.
4. [상태 타입](4-state-types.md): 저장하는 클래스에 넣을 수 있는 것과, 나중에 바꾸는 법.
5. [영상 렌더](5-render.md): 캔버스, 프레임 캡처, 오버레이 영상.

[레퍼런스](reference.md)에 모든 멤버, 로그 메시지, 저장 방식, ApiVersion 2 변경 사항이 있습니다. [다른 API](other-apis.md)는 `ReplayRuntime`과 `NativeInputPause`를 다룹니다.
